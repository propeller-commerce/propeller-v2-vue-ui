# Component reference

The package exports 74 components (plus the three default sub-components
under `components/defaults`). This page is the catalogue; every component name
links to its **props page** — each prop with its type, whether it is required,
its default and its description, plus the component's events and slots. The
full list is on [Component props](/api/components).

:::note Where the props pages come from
The components are Vue Single-File Components (`.vue`), which TypeDoc cannot
parse, so the [API reference](/api) covers the *headless* surface (composables,
the provider, the SDK seam, utilities and types). The component props pages are
generated from the SFC source with `vue-component-meta` on every docs build.
:::

Components that need infrastructure resolve it from the Propeller provider.
Install the `propellerVue` plugin once at startup with the app-wide
dependencies, then wrap the app in `<PropellerProvider>` with the per-scope
state:

```ts
import { propellerVue } from '@propeller-commerce/propeller-v2-vue-ui';

app.use(propellerVue, { graphqlClient, services, currency, configuration });
```

```vue
<PropellerProvider
  :user="user"
  :is-authenticated="isAuthenticated"
  :company-id="companyId"
  :language="language"
  :include-tax="includeTax"
  :portal-mode="portalMode"
>
  <router-view />
</PropellerProvider>
```

See [Getting started](/getting-started) and the
[PropellerProvider props](/api/components/PropellerProvider). For how the
composables behind these components reach the GraphQL backend, see the
[API integration guides](/guides/api/overview).
