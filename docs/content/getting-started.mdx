# Getting started

## Install

```bash
npm install @propeller-commerce/propeller-v2-vue-ui @propeller-commerce/propeller-sdk-v2 --install-links
```

`@propeller-commerce/propeller-sdk-v2` is a **peer dependency** — install it yourself so the
package and your application share a single SDK instance. `--install-links`
is needed on Windows for `file:` / `github:` installs.

### Peer dependencies

| Package            | Version | Required |
| ------------------ | ------- | -------- |
| `vue`              | `>=3.4` | Yes      |
| `@propeller-commerce/propeller-sdk-v2` | `*`     | Yes      |

There is **no dependency on Nuxt or `vue-router`** — nothing in the package
imports them. A plain Vite + Vue app works out of the box.

## Import the stylesheet

The package ships a precompiled stylesheet. Import it once, at your app
entry:

```ts
import '@propeller-commerce/propeller-v2-vue-ui/styles.css';
```

You do not need Tailwind in your own project — the CSS is already compiled.
(See [Styling](/styling) for how to override it.)

## Build the client and install the provider

Every component resolves its infrastructure (the SDK services, the current
user, language, currency, …) from two tiers:

- the **`propellerVue` plugin** — app-wide dependencies (`graphqlClient`,
  `services`, `currency`, `configuration`), installed once with `app.use`;
- the **`<PropellerProvider>` component** — per-scope state (`user`,
  `companyId`, `language`, `includeTax`, `portalMode`) around your routed
  tree.

You construct a GraphQL client and build the services bundle:

```ts
// src/lib/api.ts — your app owns this file
import { GraphQLClient } from '@propeller-commerce/propeller-sdk-v2';
import { createServices } from '@propeller-commerce/propeller-v2-vue-ui';

export const graphqlClient = new GraphQLClient({
  endpoint: '/api/graphql', // your endpoint / proxy path
  apiKey: '',
  timeout: 30_000,
});
export const services = createServices(graphqlClient);
```

Install both with the plugin:

```ts
// src/main.ts
import { createApp } from 'vue';
import { propellerVue } from '@propeller-commerce/propeller-v2-vue-ui';
import '@propeller-commerce/propeller-v2-vue-ui/styles.css';
import App from './App.vue';
import { graphqlClient, services } from '@/lib/api';

createApp(App)
  .use(propellerVue, { graphqlClient, services, currency: '€', configuration: {} })
  .mount('#app');
```

Then wrap the routed tree with the provider:

```vue
<!-- src/App.vue -->
<script setup lang="ts">
import { PropellerProvider } from '@propeller-commerce/propeller-v2-vue-ui';
</script>

<template>
  <PropellerProvider
    :user="null"
    language="NL"
    :include-tax="false"
    portal-mode="open"
  >
    <RouterView />
  </PropellerProvider>
</template>
```

Bind the props to your auth / company / language / price stores; the
provider stays reactive.

Why you build the client yourself is explained in
[The SDK seam](/sdk-seam) — it is the central design decision of the
package.

## Render a component

Inside the provider, drop in a component:

```vue
<script setup lang="ts">
import { ProductCard } from '@propeller-commerce/propeller-v2-vue-ui';
</script>

<template>
  <ProductCard :product="product" />
</template>
```

See the [Component reference](/components) for the full catalogue.
